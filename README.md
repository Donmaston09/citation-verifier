# citation-verifier

[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.24062770.svg)](https://doi.org/10.5281/zenodo.24062770)

Checks each reference against Crossref, DataCite, PubMed and Semantic Scholar, and flags hallucinated, mismatched, unregistered or retracted citations for you to review. It never changes your references: any suggested match is yours to accept.

Use it in the browser: https://donmaston09.github.io/citation-verifier
